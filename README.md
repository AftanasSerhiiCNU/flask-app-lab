## Тема: Структура Flask-застосунку, Blueprints та модульне тестування

**Мета роботи:** удосконалити структуру вебзастосунку Flask, реалізувати модульну організацію маршрутів за допомогою Blueprints та ознайомитися з модульним тестуванням.

## Завдання 1. Реорганізація структури проєкту

У ході виконання першого завдання було змінено структуру Flask-застосунку:

- Створено пакет `app`.
- Перенесено папки `templates` і `static` всередину `app`.
- Створення екземпляра Flask перенесено до `app/__init__.py`.
- Маршрути винесено до `app/views.py`.
- Створено окремий шаблон `homepage.html`.
- Файл запуску застосунку перейменовано на `run.py`.
- Збережено сторінки «Резюме» та «Контакти» з попередньої лабораторної.

## Завдання 2. Використання Blueprints

### 2.1. Blueprint users

Створено окремий модуль `users`, який зареєстровано у Flask з префіксом `/users`.

Реалізовано такі можливості:

- Динамічний маршрут `/users/hi/<name>` для привітання користувача.
- Отримання віку через параметр `age` у URL.
- Перетворення імені користувача у верхній регістр.
- Використання `url_for()` для формування посилань.
- Перенаправлення з `/users/admin` на сторінку привітання адміністратора.
- Шаблон `hi.html` із наслідуванням `base.html`.
- Вертикальне навігаційне меню та власні CSS-стилі.

### 2.2. Blueprint products

Створено окремий модуль `products` для відображення списку товарів і детальної інформації про кожен товар.

Для зберігання даних використано список словників Python, де кожен товар містить такі поля: `id`, `name`, `description`, `price`.

Реалізовано:
- Blueprint `products` із префіксом `/products`.
- Маршрут `/products/` для перегляду всіх товарів.
- Маршрут `/products/<int:product_id>` для перегляду окремого товару за його ідентифікатором.
- HTML-шаблон `products.html` для відображення списку товарів.
- HTML-шаблон `detail_product.html` для відображення детальної інформації.
- Обробку неіснуючих ідентифікаторів товарів через HTTP-помилку 404.
- Навігацію між списком товарів і сторінкою конкретного товару за допомогою `url_for()`.
- Оформлення сторінок із використанням Bootstrap.

### Результати роботи Blueprint products

**1. Сторінка списку товарів**

Адреса: `/products/`

На сторінці відображено три товари: Laptop, Phone та PC.

![Список товарів](screenshots/products_list.png)

**2. Сторінка детальної інформації про товар**

Адреса: `/products/1`

Сторінка містить ідентифікатор, назву, опис та ціну вибраного товару.

![Детальна інформація про товар](screenshots/product_detail.png)

**3. Перевірка неіснуючого товару**

При переході на адресу `/products/999` застосунок повертає HTTP-статус 404, оскільки товар із таким ідентифікатором відсутній.
